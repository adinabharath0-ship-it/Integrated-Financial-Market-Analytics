# Integrated Financial Market Analytics & Visualization

**A Python-Based Financial Market Analysis Project**

## About the Project
This project provides an integrated dashboard to analyze:
- Indian Stock Market
- Forex Market
- Gold Market (XAUUSD)

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Plotly
- Yahoo Finance
- HTML & CSS

## Features
- Interactive financial market dashboard
- Indian stock market analysis
- Forex and Gold market data
- Technical indicators
- Historical price charts
- Market data visualization

## Project Structure
- `app.py` – Flask application
- `src/` – Data processing and analysis
- `data/processed/` – Processed market datasets
- `templates/` – HTML pages
- `static/` – CSS and styling

## How to Run

1. Clone the repository.
2. Install dependencies:
   `pip install flask pandas numpy plotly yfinance`
3. Run:
   `python app.py`
4. Open `http://127.0.0.1:5000`
